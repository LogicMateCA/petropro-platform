# Test cases and validation feedback

We are looking for engineers and researchers willing to discuss public or shareable reservoir-simulation cases and validation methods. We can discuss running suitable cases **free of charge**. Each case will be reviewed for scope and input availability before we agree to a run.

## What would help

- A public benchmark or a case you have permission to share, with its source and version.
- Model type, grid size, active phases and the simulator/format used.
- Relevant well controls, schedules, fluid and rock data, units and report times.
- Which outputs matter to you: well oil, gas and water rates, cumulative volumes, pressure, saturation or material balance.
- Whether you can share a reference result and whether redistribution or publication is permitted.

A description is enough to start. **Do not put confidential models, proprietary data, credentials, or files you cannot share in a public issue.** For restricted data, first discuss an appropriate sharing arrangement; this public repository is not a confidential exchange.

## What to expect

We will first check whether the current candidate can accept the inputs and whether a like-for-like comparison is possible. A completed comparison depends on that assessment and access to the necessary inputs and reference outputs.

When feasible, we aim to report the candidate version, input and control assumptions, reporting times, relevant output curves, differences and unresolved limitations. Missing or non-matching outputs will be identified rather than treated as zero. A case result is not a claim of field qualification.

## Start a discussion

[Open a testing or validation issue](https://github.com/LogicMateCA/petropro-platform/issues/new/choose) or comment on an existing relevant issue. Please identify whether your question concerns a public case, an anonymized case or a validation method; do not upload restricted data publicly.

The current [results](https://petropro.app/benchmark-020.html) distinguish the black-oil core 0.2.0 baseline from historical candidates and describe available reference results and case limits.
